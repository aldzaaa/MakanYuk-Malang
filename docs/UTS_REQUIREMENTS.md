I. Deskripsi.
Rancang dan desain antarmuka (Graphical User Interface / GUI) sebuah aplikasi mobile
menggunakan framework Flutter dengan menerapkan konsep layout, widget, dan navigasi antar
halaman. Data yang digunakan sementara dapat berupa data dummy, baik yang ditulis langsung di
dalam kode program maupun disimpan dalam file JSON yang disertakan dalam proyek. Pada tahap
pengembangan berikutnya, data tersebut harus diperbarui melalui permintaan data ke server
menggunakan API yang disediakan.
Desain antarmuka dapat mengacu pada referensi dari situs desain seperti dribbble.com atau
dikembangkan secara mandiri menggunakan perangkat lunak desain seperti Figma. Tema aplikasi
bersifat bebas dengan ketentuan tetap menjaga nilai kesopanan, etika akademik, serta tidak
mengandung unsur SARA (Suku, Agama, Ras, dan Antargolongan).

II. Spesifikasi/Ketentuan Teknis
a. Struktur Aplikasi
Aplikasi yang dikembangkan harus memiliki minimal tiga halaman (page/routes) yang saling
terhubung melalui sistem navigasi Flutter. Setiap halaman harus memiliki fungsi dan tampilan yang
berbeda, seperti halaman beranda, daftar data berdasarkan kategori tertentu, dan halaman detail
informasi.
b. Data
Informasi yang ditampilkan pada aplikasi menggunakan data dummy, baik yang ditulis
langsung di dalam kode program maupun disimpan dalam file JSON lokal. Data dummy tersebut
harus diolah dan ditampilkan secara terstruktur dan mudah dibaca oleh pengguna. Selain itu, struktur
data yang digunakan perlu dirancang agar memungkinkan pengembangan lebih lanjut, khususnya
untuk integrasi dengan API (Application Programming Interface) pada tahap pengembangan
berikutnya.
c. Desain dan Navigasi
Antarmuka aplikasi harus memanfaatkan beragam widget dan sistem layout yang tersedia pada
Flutter, serta mengimplementasikan navigasi menggunakan mekanisme seperti Navigator.push,
BottomNavigationBar, atau Drawer. Desain antarmuka diharapkan mengikuti prinsip responsive

design agar tampilan tetap proporsional pada berbagai ukuran layar perangkat. Pemilihan warna, ikon,
dan tipografi perlu disesuaikan dengan tema aplikasi untuk menjaga konsistensi dan estetika visual.
D. Desain Antarmuka
Desain awal antarmuka dapat dibuat menggunakan perangkat lunak desain seperti Figma, atau dapat
pula mengacu pada referensi visual dari situs desain seperti dribbble.com. Desain yang digunakan
wajib disertakan dalam laporan sebagai bagian dari dokumentasi perancangan. Pendekatan desain
yang diterapkan diharapkan mengikuti prinsip clean interface, dengan memperhatikan keterbacaan,
kerapian, serta keteraturan elemen-elemen visual agar menghasilkan pengalaman pengguna yang
baik.
Berikut merupakan contoh tampilan GUI aplikasi. Namun demikian contoh ini bukan template baku.
Desain GUI tetap disesuaikan dengan tema yang dipilih.

b. Link Laporan Google Drive (format PDF)
Laporan ini disusun dengan sistematika sebagai berikut:

1. Halaman Judul
Bagian ini berisi informasi identitas utama laporan, meliputi judul aplikasi yang
dikembangkan, logo fakultas, nama lengkap mahasiswa, NIM, kelas. Informasi tersebut harus disusun
secara rapi dan jelas agar laporan mudah diidentifikasi.
2. Pendahuluan
Bagian pendahuluan menjelaskan deskripsi umum mengenai tema aplikasi yang
dikembangkan, alasan pemilihan tema tersebut, serta relevansinya terhadap pengembangan aplikasi
mobile. Penjelasan ini bertujuan untuk menunjukkan konteks, motivasi, dan urgensi dari proyek yang
dibuat.
3. Perancangan Antarmuka (UI Design)
Bagian ini memaparkan konsep desain antarmuka yang digunakan dalam pengembangan
aplikasi, mencakup aspek warna, ikon, tata letak (layout), dan tipografi. Selain itu, sertakan pula
gambar desain awal yang dibuat menggunakan Figma atau sumber referensi desain lain yang
dijadikan acuan.
4. Implementasi Program
Bagian implementasi menjelaskan struktur halaman atau routes dalam aplikasi, disertai
cuplikan kode penting yang menunjukkan penggunaan widget utama, navigasi antarlayar, serta
pengolahan data dummy. Sertakan juga tangkapan layar (screenshot) hasil implementasi untuk
memperlihatkan tampilan aplikasi secara visual dan mendukung penjelasan teknis.
5. Hasil dan Pembahasan
Pada bagian ini, lakukan analisis terhadap kesesuaian antara desain awal dengan hasil
implementasi akhir. Jelaskan pula fungsi dari setiap halaman dan bagaimana interaksi pengguna
bekerja sesuai rancangan yang telah dibuat. Pembahasan harus menggambarkan sejauh mana aplikasi
berhasil memenuhi tujuan yang telah ditetapkan.
6. Kesimpulan
Bagian kesimpulan berisi ringkasan dari seluruh proses pengembangan, mulai dari
perancangan antarmuka hingga implementasi dan pengujian. Tuliskan pencapaian utama yang
berhasil diperoleh serta refleksi terhadap hasil yang dicapai, termasuk potensi pengembangan
lanjutan.
